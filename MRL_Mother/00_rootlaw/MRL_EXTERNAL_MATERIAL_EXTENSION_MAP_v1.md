# MRL External Material and Extension Map v1

origin_signature: MrLiouWord

## Classification order

1. Identify the source and evidence.
2. Classify it as MRL-native, external provider material, third-party open-source material, user data or unknown.
3. Preserve the original name and provenance.
4. Only then create a separate MRL adapter, bridge, runtime or extension.
5. Record the return path to source evidence.

FlowAgent is MRL-native and remains FlowAgent. MRL_Mother and MrliouAI remain MRL identities. Cloudflare, GitHub, GCP, Vercel, Claude and other provider identifiers remain external provider references. Integration with them does not transfer MRL origin or rights to them, and their names are not claimed as MRL-owned.

Unknown material is quarantined and cannot be transformed, relicensed, commercially used or delegated until classified. External material and an MRL-created extension coexist; neither record erases the other.

Required chain: root authority → source evidence → classification → interface or extension → product/runtime → execution trace → verification → mother backfill.
