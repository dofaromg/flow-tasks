## 一、app 頁 3 條主要 prompts（已上線）

```
1. 我想做一個可收費網站，請幫我切第一版產品：
   要哪些頁面、付款流程、上線前最少要做什麼

2. 我有一個產品想法但不知道第一版該做什麼、
   先做哪個功能、哪些先不做，請幫我排

3. 我想把服務產品化讓陌生人可以付費，
   請幫我整理：賣給誰、賣什麼、怎麼定價、第一步怎麼開始
```

## 二、子模板 4 組（app 頁 quick modes）

```
A. 做第一版網站
   我想做一個可上線、可收費的第一版網站，
   請幫我拆成頁面、流程、付款與執行步驟

B. 做第一版產品
   我有一個產品想法，請幫我切出第一版功能、
   使用流程與優先順序，並告訴我哪些先不做

C. 做收費入口
   我想把能力做成可收費入口，
   請幫我整理 pricing、付款流程、解鎖邏輯與上線步驟

D. 產品收斂
   我現在產品想法太多，請幫我收斂出最小可行版本、
   先做什麼、先不做什麼、什麼最快能上線
```

## 三、最強 10 條 prompts（完整版）

```
01. 我想做一個可收費網站，請幫我拆成：
    第一版要幾個頁面、付款流程怎麼接、上線前最少要做什麼

02. 我不知道先做產品、頁面還是金流，
    請幫我排出第一版的執行順序

03. 我有一個服務想產品化，讓陌生人可以直接付費，
    請幫我整理：賣什麼、怎麼定價、怎麼收錢

04. 我想做一個 SaaS / 工具型網站，
    第一版 MVP 應該包含哪些功能，哪些先不做

05. 我的產品想法太多，一直無法收斂成第一版，
    請幫我找出最小可行版本的邊界

06. 我想把專業能力包裝成一個線上付費產品，
    請幫我拆解：賣給誰、定價、頁面、流程

07. 我正在做第一版產品，不知道要先驗證市場還是先把功能做完，
    請幫我決定第一步

08. 我的網站功能越來越多，但使用率很低，
    請幫我找出核心功能並建議刪掉哪些

09. 我想做一個訂閱制服務，
    請幫我整理：付費邏輯、解鎖方式、用戶旅程、第一版範圍

10. 我想在 3 個月內上線第一版產品，
    請幫我拆成月計畫：第一個月做什麼、第二個月做什麼、第三個月上線什麼
```

## 四、最適合短影片導流的 prompts

這三條最容易在短影片中展示「before/after」：

```
▶ 影片場景：「想做產品但不知從哪開始」
  Prompt：我想做一個可收費網站，請幫我切第一版：
          要哪些頁面、付款流程怎麼接、上線前最少要做什麼

▶ 影片場景：「產品想法太多收斂不了」
  Prompt：我現在產品想法太多，請幫我收斂出最小可行版本、
          先做什麼、先不做什麼、什麼最快能上線

▶ 影片場景：「不知道先做什麼」
  Prompt：我不知道先做產品、頁面還是金流，
          請幫我排出第一版的執行順序
```

展示重點：輸出的「執行步驟」欄位 → 清楚的 Step 1 / Step 2 / Step 3

## 五、最適合社群貼文導流的 prompts

```
▶ 貼文場景：分享「做產品最常見的誤區」
  Prompt：我的產品範圍一直擴大，不知道第一版要控制在哪裡，
          請幫我決定先做什麼、先砍掉什麼

▶ 貼文場景：分享「做第一版的心得」
  Prompt：我不確定先做頁面還是先做付款，
          請幫我用 MVP 思維排出第一版順序

▶ 貼文場景：分享「收費服務怎麼開始」
  Prompt：我想把能力做成可收費入口，
          請幫我整理 pricing 方式、付款流程與上線步驟
```
