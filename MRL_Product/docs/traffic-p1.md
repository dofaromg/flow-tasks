## 核心原則（執行前必讀）

```
❌ 不導首頁 /
❌ 不導 /pricing
✅ 全部導 /app.html?cat=XXX
```

人不是為產品來，是為問題來。
每一則內容要講的是「有這種問題的人」，不是「我做了一個工具」。

## 四、觀測指標（在 /admin.html 的「問題分類」tab 查看）

| 觀測問題 | 數據 | 行動 |
|---------|------|------|
| 哪個 category 分析最多？ | `analyzes` 數字 | 主打該類型的內容 |
| 哪個 category 付款率最高？ | `click_rate` | 重點投放該賽道 |
| 哪個 category 解鎖率高？ | `unlock_rate` | 代表 partial 質量好 |
| 哪個 category 流失大？ | 分析多但點擊少 | 優化該 category 的 partial |

---

## 五、成功定義

第一週結束時只問三件事：

- [ ] 有人從外部 URL 進來？（看 `page_view_app` 事件的 referrer）
- [ ] 有人用 analyze？（看 admin/category 的分析次數）
- [ ] 有人付第一筆錢？（看 admin/metrics 的付款數）

三件都有 → 第八包成立。
只有第一件 → 正常，繼續發內容。
一件都沒有 → 問題在流量入口，重新看內容格式。
