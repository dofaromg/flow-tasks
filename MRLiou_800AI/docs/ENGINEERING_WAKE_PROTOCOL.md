# Engineering Wake Protocol

Before engineering execution:

1. Capture scope and expected files.
2. Search prior work and project indexes.
3. Check actual runtime/repository state when access exists.
4. Separate facts, inferences, and unverified assumptions.
5. Build an additive plan; preserve parent and child dependencies.
6. Execute only after the dependency path is explicit.
7. Run verification, requested-vs-generated diff, checksums, and package audit.

This package does not falsely claim external Notion, Cloudflare, GitHub, or DL580 checks were performed. Such evidence must be supplied to `/tasks/dispatch` or attached to a run.
